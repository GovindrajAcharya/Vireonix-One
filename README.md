# Vireonix One

A modern, dark-themed AI video editing web application built with React and Vite.

## Features

- **AI Prompt Editor** — Describe video edits in natural language
- **Video Preview Canvas** — Cinematic 16:9 preview with playback controls
- **Timeline Editor** — Multi-track timeline with video, audio, and voice tracks
- **Audio Mixer** — DAW-style mixer with Master, BGM, Voice, and SFX channels
- **AI Inspiration Chat** — Creative assistant for generating scene ideas and visual concepts
- **Dark Theme** — Glassmorphism, neon purple/indigo accents, and soft glow effects

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- React 19
- Vite 8
- Lucide React (icons)
